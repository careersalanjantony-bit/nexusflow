Projects & engagements

Infrastructure work doesn't produce screenshots. So here's what these projects actually were: the problem, what I did, and what changed as a result.

🚚 Migration

CentOS 7 → AlmaLinux 8 fleet migration

CentOS 7 hit end of life with a live shared-hosting fleet still on it. I planned the move to AlmaLinux 8 in batches: build the new host, sync accounts, verify against a written test list, cut DNS, keep the old server warm as rollback.

AlmaLinuxcPanelrsyncDNSEOL

→ Fleet off EOL, zero reported data loss

🛡️ Security

Fleet-wide hardening baseline

Years of manual setup had left every server subtly different. I defined one CIS-aligned baseline — SSH policy, firewall rules, sysctl parameters, fail2ban, audit logging — and rolled it out with Ansible so it stays consistent.

AnsibleCISCSFSSHauditd

→ One reproducible baseline, drift eliminated

🚨 Incident

Cross-account defacement containment

A vulnerable CMS plugin let an attacker write across accounts on a shared host. I isolated the server, scoped the blast radius from file timestamps and access logs, removed the backdoors, restored from known-good backup, then closed the hole.

ForensicsmaldetModSecurityIR

→ Contained same day, RCA delivered to customers

⚡ Performance

Load-average firefight on a shared host

A busy shared server was sitting at load 40+ with customers timing out. Triage showed I/O wait, not CPU — an unindexed query on one large site was hammering disk. Indexed the table, tuned the MySQL buffer pool, capped the offending pool.

MySQLiostatPHP-FPMTuning

→ Load average back under 2, timeouts stopped

📦 Migration

Agency portfolio move, single weekend

40+ client sites moving from an ageing VPS to a new managed server. TTLs dropped days in advance, full sync on Friday, delta sync Saturday night, DNS cut with the old host left serving until the last resolver caught up.

WordPressTTLLet's EncryptDelta sync

→ No client-reported downtime

✉️ Deliverability

Mail reputation recovery

A client's transactional mail had been landing in spam for months. The cause was a stack of small things: a broken SPF include chain, unsigned DKIM on one sending source, no DMARC, and a stale blacklist entry nobody had ever contested.

SPFDKIMDMARCPostfixRBL

→ Inbox placement restored, delistings cleared

⚙️ Automation

Backup verification pipeline

The backups were "running fine" — nobody had restored one in a year. I built a scheduled job that pulls a random account nightly, restores it into an isolated environment, checks the site responds, and reports a pass or fail.

BashcronJetBackupDR

→ Backups proven, not assumed

📊 Monitoring

Alert fatigue cleanup

The on-call rota was ignoring alerts because most of them were noise. I rebuilt thresholds around symptoms customers actually feel, added sane hysteresis, and deleted every check that had never once led to an action.

ZabbixGrafanaOn-callSLO

→ Fewer pages, higher signal, faster response

🐘 Upgrade

Fleet-wide PHP & MySQL upgrade

Legacy PHP versions were blocking security patches. I inventoried every site's PHP usage, staged upgrades per-account with a per-domain version override, and gave customers a compatibility window before the old handler was withdrawn.

PHP-FPMMariaDBMultiPHPStaging

→ Fleet on supported versions, no forced breakage
